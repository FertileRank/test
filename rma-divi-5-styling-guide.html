How this system works.

All styling is driven by CSS custom properties (design tokens) defined once in :root. Change a token and the whole site updates. Reusable helper classes are prefixed .rma-; everything targeting .et_pb_ restyles Divi's native modules. Prefer editing tokens over hard-coding values.

Section 1

Installing in Divi 5

There are two supported places to load this stylesheet. Use the first for everything global; use the second only when a page needs the CSS to win against Divi's cached styles.

A

Theme Options (recommended)

Divi → Theme Options → General → Custom CSS. Paste the entire rma-global.css. Loads site-wide on every page.

B

Global Header Code Module

Wrap the CSS in a <style> block inside a Code Module near the end of the Theme Builder Global Header. Loads after Divi's cached CSS, so it wins specificity battles.

Load order & the !important rule

Divi injects its own inline module styles with high specificity. Many rules here use !important to override them reliably — that is intentional, not a code smell. When adding new rules that target Divi modules, follow the same pattern.

Method B — Global Header Code Module 
<style>
  /* Paste the full contents of rma-global.css here */
  :root { --rma-blue: #123883; /* … */ }
  /* … rest of stylesheet … */
</style>
Do & Don't
  • Keep the Google Fonts @import at the very top — DM Serif Display and DM Sans must load or the brand type falls back.
  • Don't paste it into individual pages — that duplicates rules and makes future edits hard to find.
  • Don't strip the Critical Sitewide Layout Fix at the bottom; it prevents horizontal scroll and powers full-width heroes.
Section 2

Logo & Clear Space

The RMA of Michigan mark pairs the interlocking-rings symbol with the tagline "The Source for New Beginnings." Protect it with breathing room and adequate contrast.

Clear Space

Keep padding equal to the height of the "RMA" letterforms on all sides. Never crowd the mark with text or buttons.

Minimum Size

Do not display below 120px wide on screen so the tagline stays legible.

Reversing

On dark backgrounds, use the all-white version. The header/footer achieve this with a CSS filter.

Reverse the logo to white on dark backgrounds

CSS 
/* Add class "rma-logo-reverse" to the logo image module */
.rma-logo-reverse img {
  filter: brightness(0) invert(1);
}

Section 9

Layout & Full-Width Fixes

The Critical Sitewide Layout Fix at the bottom of the stylesheet solves two recurring Divi problems: horizontal overflow, and forcing Code Module heroes / Theme Builder header & footer blocks to true full width.

Row widths

.et_pb_row caps at 1140px. Add .rma-row-wide (1280) or .rma-row-narrow (780).

Full-width code

Add class .fullwidth-code-section to any Section holding a Code Module hero.

No horizontal scroll

overflow-x: clip on body, with a hidden fallback for older browsers.

Section background helpers

.rma-bg-white
.rma-bg-offwhite
.rma-bg-blue
.rma-bg-navy
CSS · layout fix 
html, body, #page-container, #et-boc { max-width: 100%; }
body { overflow-x: clip; }
@supports not (overflow: clip) {
  body { overflow-x: hidden; }
}

.et_pb_row { max-width: 1140px !important; }
.et_pb_row.rma-row-wide   { max-width: 1280px !important; }
.et_pb_row.rma-row-narrow { max-width: 780px  !important; }

/* Force a Code Module section to true full width */
.et_pb_section.fullwidth-code-section { padding: 0 !important; }
.fullwidth-code-section .et_pb_row,
.fullwidth-code-section .et_pb_column,
.fullwidth-code-section .et_pb_code,
.fullwidth-code-section .et_pb_code_inner {
  width: 100% !important;
  max-width: 100% !important;
  margin: 0 !important;
  padding: 0 !important;
}

Section 11

Accessibility & Print

The stylesheet ships with sensible defaults for keyboard users, reduced-motion preferences, and clean printed pages.

Focus rings

Every interactive element gets a 2px brand-blue :focus-visible outline with offset.

Skip link

.screen-reader-text appears on focus as a fixed skip-to-content pill.

Reduced motion

Honors prefers-reduced-motion by near-zeroing all transitions.

Print

Hides header, footer & buttons; switches to 12pt black body text with underlined links.

CSS · a11y & print 
a:focus-visible, button:focus-visible, .et_pb_button:focus-visible,
input:focus-visible, textarea:focus-visible {
  outline: 2px solid var(--rma-blue);
  outline-offset: 2px;
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

@media print {
  #main-header, #top-header, #main-footer,
  .et_pb_button, .et-social-icons { display: none !important; }
  body { font-size: 12pt; color: #000; line-height: 1.5; }
  a { color: #000; text-decoration: underline; }
}
